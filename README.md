# US-Insurance-Costs
# Overview
This project focuses on analyzing a health insurance dataset to understand how various demographic and lifestyle factors affect insurance charges. The primary goal was to uncover insights that could help inform better decision-making in the insurance industry.

# Key Features
## Exploratory Data Analysis (EDA):
Performed detailed analysis to identify trends and patterns within the dataset, including breakdowns by gender, age, smoking status, and region.

## Multiple Regression Analysis:
Developed a multiple linear regression model to predict insurance charges based on factors such as age, BMI, smoking status, and gender. This helped to identify significant relationships between these variables and insurance costs.

## Visualization:
Used Python libraries such as matplotlib and seaborn to visualize the data and regression results, making complex insights more accessible.

## Data Preprocessing:
Applied necessary transformations, including one-hot encoding for categorical variables and scaling, to prepare the dataset for modeling.

## Tech Stack
Languages & Libraries: Python, pandas, statsmodels, matplotlib, seaborn
Tools: Jupyter Notebook
Data Source: insurance.csv dataset
